# QI 文字成画 · QI Word Art Generator

把一本小说变成一张图。

载入 **EPUB / TXT** 小说和一张**参考图**，工具会把小说里的文字按图片的明暗铺满画布——**亮的地方字小、暗的地方字大**，远看就是那张图。整站是**单个 HTML 文件**，无构建、无依赖、无后端，双击即用。

> 文字成画 / word art / word cloud silhouette

---

## 渲染模式

| 模式 | 说明 |
| --- | --- |
| **阳刻** | 浓墨落于暗部，字为实。暗的地方字密，亮的地方留白 |
| **阴刻** | 浓墨落于亮部，字为虚。与阳刻相反 |
| **文字底纹** | 文字作纸底铺满整幅，主体抠图叠在上层 |
| **文字填充** | 词云填满主体轮廓，大词浮出、小词成质地 |

## 取词

- **三种语言**：日本語 / 中文 / English，可手动切换或自动识别（按假名・汉字・拉丁字母占比判定）
- **两种取词范围**：随机取词（可换种子重抽）· 高频词（按实义词排序，可手动排除）
- **仅取台词**（文字底纹 / 文字填充专属）：只保留 `「」`、`“”`、`""` 成对引号里的内容，以及 `：` 之后的内容

## 可调项

列数（决定字号）· 字号上下限 · 加粗强度 · 透明度下限 · 前景抠图与反相 · 排版方向 · 彩色变化 · 文字底纹的叠加强度

调好后点 **导出 PNG** 保存。

1. 下载 `index.html`
2. 用浏览器打开（推荐 Chrome / Edge）
3. 左侧载入小说与参考图，调参数，导出

也可以直接丢进 GitHub Pages 用。

## 一些实现上的取舍

写这个工具时踩到的坑，记在这里免得下次再踩：

- **词云必须过滤实义词。** 一开始词表只滤了标点，结果 了・的・她・着 这些频次最高的虚词成了**最大的字**，把 夏天・约定 挤到很小，画面就是一片虚词。中日靠「文字种类」判实义，英文靠「长度 + 首字母大小写」。
- **相邻虚词会被分词器粘成二元组。** `也+不` → `也不`、`就+都` → `就都`，两个字都在停用词表里、整词却不在，于是靠频次冲到大号。补了一份功能词二元组黑名单。
- **字号按排名而非绝对频次。** 绝对频次在不同语料间差好几个数量级，`imp = (1 - rank)^2.6` 跨语料稳定。
- **多趟重复铺词。** 英雄词铺满后整张词表重洗、按 0.58/0.38/0.30 缩放再铺，直到真的塞不下。这是参考图那种「同一批词以不同大小反复出现」的质感来源。
- **软重叠。** 每格记 `occurrence`，大词限 1、中词 2、小词 3，允许碎片叠印——比严格不重叠更像手作词云。
- **旋转要走矩阵而不是 `save/rotate/restore`。** 后者每个旋转词都强制逐字重栅格化，实测绘制 **642ms**；换成手工 `setTransform` 后降到 **5–12ms**。
- **引号配对必须写成交替而不是字符组。** `[「『“"]…[」』”"]` 会让「和」跨对匹配，把整段叙述吞进来。

## 安全

这是一个**纯本地**的单文件工具。它不联网、不写盘、不读剪贴板：

- **零外部依赖** —— 唯一用到的 JSZip 3.10.1 已内联进 HTML（附官方 sha512 校验值），
  整个文件**不发起任何网络请求**
- **CSP 哈希白名单** —— 没有 `'unsafe-inline'`，`script-src` / `style-src` 只认本文件那两段
  内联脚本和那一段样式的 sha256。**任何后来被塞进文件的脚本都不会执行。**
  另有 `connect-src 'none'` 等 14 条指令，从浏览器层面堵死数据外传
- **输入大小上限** —— TXT/HTML/EPUB 24 MB、图片 32 MB、图片 4000 万像素，
  EPUB 还有解压炸弹防护（单条目 8 MB / 累计 96 MB / 条目数 5000）
- **输出转义** —— 唯一一处 `innerHTML` 已用 `escHtml()` 处理，
  载入的小说里就算藏了 `<img onerror=...>` 也只会被当普通文字显示
- 不存在 `fetch` / `XMLHttpRequest` / `WebSocket` / `eval` / `localStorage` / `document.cookie`

你可以自己验证：打开页面 → `F12` → **Network** 面板 → 勾上 Preserve log → 刷新 →
载入小说、调参数、导出。**全程不应该有任何请求。**

当前版本指纹：


> **改代码的人注意**：CSP 哈希是对脚本正文逐字节计算的，**改一个空格都会失配、页面会白屏**。
> 改完 `index.html` 后必须跑 `node tools/csp-hash.mjs index.html` 重新签名。
> 仓库里加了 `.gitattributes`（`* -text`）禁止行尾转换，否则 Windows 上 clone 下来哈希就会错。

详细的威胁模型、五种自查方法和**账号加固清单**见 [SECURITY.md](SECURITY.md)。
